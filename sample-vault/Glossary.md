# Glossary

**Vault** — A folder on disk that contains Markdown notes and attachments. Obsidia only
writes inside this folder (plus its own settings under `.obsidia`).

**Note** — A Markdown file inside the vault. Any `.md` or `.markdown` file is a note.

**Attachment** — A non-Markdown file inside the vault, such as an image, PDF, audio file or
video. Attachments can be linked with `[[file.png]]` or the usual Markdown syntax.

**Wiki link** — A link written as `[[Note name]]`. It can point to a heading with
`[[Note#Heading]]` and show a different label with `[[Note|Label]]`.

**Embed** — A wiki link prefixed with `!`, for example `![[Note]]` or `![[image.png]]`.

**Backlink** — A link from another note to this one. The Backlinks panel lists them.

**Reading view** — The rendered form of a note. Source view shows the Markdown text.

**Graph** — A visual map of notes and links. The local graph limits the map to the current note
and its neighbours.

See also [[Welcome]] and [[Ideas]].
